# Maintainers

Current maintainer: Mikko Kotila ([mikkokotila](https://github.com/mikkokotila), <mailme@mikkokotila.com>).

Maintainers own release approval, security triage, issue priority and merge decisions. `mikkokotila` is the approving authority in `governance.yml`. An approval must come from a reviewer eligible under the live ruleset; authors cannot approve their own changes.

The recorded code owner is currently `mikkokotila` alone. Governance activation for maintainer-authored PRs requires another eligible code owner; appoint one through a reviewed change before enabling enforcement.

[SETUP.md](SETUP.md) records the external activation requirements. [GOVERNANCE.md](GOVERNANCE.md) describes decisions and [CLAUDE.md](CLAUDE.md) describes merge contracts.
